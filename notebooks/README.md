# Notebooks

Notebooks de treino usados no TCC (Google Colab e Kaggle).

| Notebook | Modelo | Situação |
|---|---|---|
| `darknet.ipynb` | YOLOv4-tiny / YOLOv7-tiny | a adicionar |
| `NanoDet_Treinamento_GadoGPU.ipynb` | NanoDet-Plus (treino final, GPU) | a adicionar |
| `NanoDet_Treinamento_GadoCPU.ipynb` | NanoDet-Plus (tentativa em CPU, interrompida na época 7) | a adicionar |
| `detr_custom_training_tutorial.ipynb` | DETR | a adicionar |

Parte dos notebooks originais se perdeu. As configurações, os logs e os pesos preservados permitem reproduzir os treinos (veja o README de cada modelo).

Antes de adicionar um notebook, remova chaves de API (por exemplo, do Roboflow) e caminhos pessoais do Google Drive.
